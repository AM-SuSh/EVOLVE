# C7 试用校准与修订记录

## 数据边界

- 本次使用 `traces-lab2-mock.json` 的 20 条人工标注轨迹完成离线校准。
- 这些记录是教学专家构造/标注样本，不是真人试用数据；真人招募仍按 `trial-protocol-m5.md` 待线下执行。
- 因此本次只修订“教师分析中的建议就绪阈值”，不修改可信解锁、rubric v2 自动分或最终成绩。

## 修改前

- 建议就绪阈值采用常见基线 `70`。
- 以人工总分 `>=70` 为参照，20 条样本中出现 3 个假阳性、1 个假阴性。
- 准确率 `0.80`，平衡准确率 `0.8125`。假阳性集中在“退出码 0 假通过”“空反思”“教师复核后下调”等证据不足轨迹。

## 搜索方法

- 遍历 `0..100` 的整数阈值。
- 优先最大化 sensitivity 与 specificity 的平均值（balanced accuracy），减少类别数量不均造成的偏差。
- 并列时选择更接近原阈值的候选。

## 修改后

- `calibration-policy-v1.json` 将建议就绪阈值设为 `76`。
- 假阳性从 3 降为 0，假阴性保持 1；准确率升至 `0.95`，平衡准确率升至 `0.9375`。
- 匿名分析导出使用该阈值生成 `advisoryReady`，仅供教师筛选，不替代 C4 证据评分与 C5 教师复核。

## 后续复核条件

真人试用达到至少 5 人后重新运行校准，并同时报告样本量、混淆矩阵和失败案例。若样本构成或量规版本变化，不能沿用本阈值而不重新验证。
