## 通用 UI 文案

| 键 | 文案 |
| --- | --- |
| `opre.title` | 观察 → 预测 → 运行 → 解释 |
| `opre.hint` | 每步写一句即可；可用「插入报告」写入过程记录。 |
| `opre.empty_trace` | 当前 run 无可用 trace。可先看输出断言，或换一次带 trace 的可信运行。 |
| `opre.degraded` | 视图未就绪：请按降级说明用源码/输出完成，并在报告注明。 |

## Lab2 · T-OPRE-1（Trap 视图旁）

| 步 | 按钮旁短句 | 插入报告模板 |
| --- | --- | --- |
| 观察 | 数一数本次 `trap_enter` | 【观察】本次 run 中 trap_enter 约 ___ 条。（run:___） |
| 预测 | Yield×5 时 trap 会多于 5 吗？ | 【预测】我认为 trap_enter ___（会/不会）明显多于 5，因为 ___。 |
| 运行 | 使用可信 Lab2（含 trace） | 【运行】已执行受信验证；断言结果：___。 |
| 解释 | 区分 ecall 与其它 trap | 【解释】多出来的 trap 可能来自 ___；若无法区分，记「未观察到」。 |

**通过（教学）**：解释中出现「用户 ecall」意识；数据不足时写明未观察到。
