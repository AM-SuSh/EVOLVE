# 教师审核清单（Lab 变式 / 新包）

成员 A · 第 8–9 周。任一「否」不得发布到测试班。

## 教学正确性

- [ ] 学习目标与基线 Lab 知识点一致或明确标注增量
- [ ] 误区列表覆盖至少 2 个真实学生错误
- [ ] 提示阶梯不泄露完整答案；L3 仍留推理空间
- [ ] 迁移题或反思提示存在

## 证据与评分

- [ ] 成功标准绑定受信 recipe + 命名断言（非仅 exit 0）
- [ ] 至少 2 条负向测试；写明假通过方式
- [ ] 量规细项可引用（P/R/F/T 或新增 id）
- [ ] 触发强制复核的情形已评估（见 `teacher-review-gates.md`）

## 工程可发放

- [ ] `lab.yaml` / variant manifest 字段齐全
- [ ] 源文件路径存在；不覆盖原则已说明
- [ ] 与 `run-recipes` / 手册断言文本一致（或已提 C 改契约测试）
- [ ] 文档链接（manual_anchor）可打开

## 难度与公平

- [ ] 预估时间合理（与基线 Lab 的目标时长和学生负担匹配）
- [ ] 无障碍：不依赖尚未交付的可视化（有降级路径）
- [ ] 班级差异：是否需按班级分配已说明
