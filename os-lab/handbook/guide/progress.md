# 学习进度

本页集中展示 **Lab1–Lab5** 的学习清单、验证命令与期望输出。勾选状态保存在浏览器 `localStorage`，便于分多次完成实验时续接进度。

<LabProgress />

## 使用说明

1. 在仓库根目录激活环境并进入 `os-lab`（见上方「环境激活」命令）。
2. 每完成一个 Lab 的 QEMU 验证，勾选对应步骤。
3. 文字习题不要求写代码，做完后再勾「完成文字习题」。
4. 需要从零核对时，点击「清空进度」。
