# 学习进度

> 在[引导式学习工作台](/guide/ai-tutor)中学习会自动记录成长档案（含验证与复盘证据），不需要本页。本页是纯阅读路径的手动勾选清单。

本页集中展示 **Lab1–Lab8** 的学习清单、验证命令与期望输出。勾选状态保存在浏览器 `localStorage`，便于分多次完成实验时续接进度。

<LabProgress />

## 使用说明

1. 在仓库根目录激活环境并进入 `os-lab`（见上方「环境激活」命令）。
2. 每完成一个 Lab 的 QEMU 验证，勾选对应步骤。
3. 【任务二】阅读理解与思考题不要求写代码，做完后再勾对应步骤，并可对照参考答案自查。
4. 需要从零核对时，点击「清空进度」。
