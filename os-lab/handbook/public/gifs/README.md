# GIF 占位目录

`start.md` 中的 `![...](/gifs/xxx.gif)` 是预留的录屏占位。本目录已附带同名静态占位 GIF；录制完成后，用录屏文件覆盖同名文件即可。

| 文件名 | 建议录制的操作 | 建议时长 |
| --- | --- | --- |
| `guide-entry.gif` | 学生注册/登录，进入引导式学习并自动定位当前 Lab | 10–15 秒 |
| `workbench-layout.gif` | 工作台三区布局：手册、工作区、学习支持、底部面板 | 10–15 秒 |
| `journey-claim.gif` | 打开系统构建路径，查看锁定原因并「领取并开始」下一层 | 8–12 秒 |
| `run-and-test-results.gif` | 编辑代码、保存、运行可信验证、查看 Problems 与测试结果 | 15–20 秒 |
| `report-socratic-review.gif` | 填写实验报告、完成苏格拉底复盘并提交给老师 | 15–20 秒 |
| `ai-tutor-evidence.gif` | 打开 AI 导师，附上代码/终端/断言证据并提问 | 10–15 秒 |
| `teacher-publish-review.gif` | 教师创建班级、按范围分发 Lab，并在实验验收页查看提交 | 15–20 秒 |

建议使用 1080p 或与工作台接近的窗口尺寸录制，避免文字过小；动图命名保持 ASCII，方便静态站点引用。
