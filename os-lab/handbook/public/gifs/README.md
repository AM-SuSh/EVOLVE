# GIF 录制需求清单

本文档是 `os-lab/handbook/guide/start.md` 第三部分「引导式学习平台操作指南」的录屏 GIF 需求汇总。`start.md` 中已经留好位置和描述，录制完成后用同名文件覆盖本目录下的占位图即可。

## 总览


| 文件名                          | 对应章节             | 建议时长    | 一句话用途           |
| ---------------------------- | ---------------- | ------- | --------------- |
| `guide-entry.gif`            | 3.1 登录、注册与进入工作台  | 10-15 秒 | 注册登录后自动进入当前 Lab |
| `workbench-layout.gif`       | 3.2 工作台布局        | 10-15 秒 | 展示三区布局、底部面板与分隔条 |
| `journey-claim.gif`          | 3.3 系统构建路径与领取并开始 | 8-12 秒  | 查看锁定原因并领取下一层    |
| `run-and-test-results.gif`   | 3.4 一次 Lab 的标准操作 | 15-20 秒 | 编辑代码、可信验证与测试结果  |
| `report-socratic-review.gif` | 3.4 报告、复盘与学习评价   | 15-20 秒 | 报告、苏格拉底复盘与提交    |
| `ai-tutor-evidence.gif`      | 3.5 AI 导师与证据附件   | 10-15 秒 | 附证据提问并查看导师引导    |
| `teacher-publish-review.gif` | 3.6 教师端快速上手      | 15-20 秒 | 教师分发实验与实验验收     |
| `final-project.gif`          | 可选：期末探索任务        | 10-15 秒 | 内核年轮与期末任务提交     |




## 通用录制要求

- 使用 1080p 或接近工作台实际窗口的尺寸录制，避免文字过小。
- 单段控制在 15-20 秒以内；需要展示失败到修复时不要贪多，保留最关键的过程。
- 文件名保持 ASCII；最终覆盖 `os-lab/handbook/public/gifs/` 下的同名文件。
- 使用演示账号与演示班级录制，不要出现真实密码、真实学号或个人资料。
- 动图里的对话、报告、复盘内容使用示例数据；不要为了演示伪造可信 run、断言或通过状态。
- 页面出现加载或等待时，等结果稳定后再切下一段，避免录到半空状态。



## 逐条录制说明



### 1. `guide-entry.gif`（3.1，10-15 秒）

**镜头**

1. 从站点顶栏点「引导式学习」进入未登录的登录门。
2. 切换到「注册」，填写演示用户名或学号、密码，在班级下拉框选择老师已创建的班级。
3. 注册后直接登录，页面自动跳转到当前 Lab 工作台。
4. 可补充 1 秒空态：注册页提示「教师尚未创建班级」时，学生应先联系老师。

**需要露出的 UI**

- 登录门
- 班级下拉框
- 登录后的自动跳转
- 顶栏「我的系统 · labN」

**建议标注**

- 学生注册时必须选择老师已创建的班级
- 登录后自动进入当前应学习的 Lab

**注意**

使用演示账号录制，不要录真实密码。

### 2. `workbench-layout.gif`（3.2，10-15 秒）

**镜头**

1. 静止展示三区：左侧实验手册、右侧上方工作区、右侧下方学习支持。
2. 学习支持里露出「实验报告 / 学习评价」两个页签，右下角露出 AI 导师悬浮按钮。
3. 切到底部面板，依次展示「终端 / Problems / 测试结果」三个页签，并展示终端右侧的多会话列表。
4. 演示分隔条拖动：手册与工作区之间、工作区与学习支持之间、编辑器与终端之间各拖一次。
5. 演示顶栏「手册 / 工作区 / 学习支持」收起与恢复。

**需要露出的 UI**

- 左侧手册及目录
- 右侧工作区文件列表与编辑器
- 学习支持页签
- 底部终端 / Problems / 测试结果
- 右下角 AI 导师悬浮按钮

**建议标注**

- 左边读手册，右边改代码，下面看证据
- 分隔条可拖动，浏览器会记住常用布局



### 3. `journey-claim.gif`（3.3，8-12 秒）

**镜头**

1. 打开顶栏「系统构建路径」，展示 Lab1-Lab8 与期末任务节点。
2. 先停留在某个未解锁层，读出锁定原因，例如「教师尚未手动分发该实验」「尚未到解锁时间」「任务已截止」或「前置条件未完成」。
3. 定位到已解锁但未领取的层，点击「领取并开始」。
4. 等待代码合并，展示顶栏「我的系统 · labN」同步更新和成功提示。
5. 把鼠标移到该层证据状态上，展示「运行验证」「学习复盘」和成长证据条数。
6. 可顺带展示底部「导出成长档案」。

**需要露出的 UI**

- 系统构建路径的 8 个系统层
- 期末任务节点
- 未解锁层的锁定原因
- 「领取并开始」按钮
- 证据状态与成长证据条数
- 「导出成长档案」

**建议标注**

- 未解锁的层会写明缺什么
- 点击领取并开始后，代码才进入我的系统



### 4. `run-and-test-results.gif`（3.4，15-20 秒）

**镜头**

1. 在左侧手册中找到「验证」部分，让验证命令保持可见。
2. 打开任务要求的源码文件，展示 A/M/T/G/! 文件状态徽章，修改一段代码并保存。
3. 切到底部「终端」，执行与手册一致的可信验证命令，例如 `cargo run -p kernel --features labN --release` 或 `make test-labN`，等待完整输出。
4. 如果录制条件允许，拍一次失败到修复的完整过程：先让 Problems 出现诊断，点击条目跳回对应文件和行号，修改后重新运行。
5. 切到「测试结果」页签，展示期望值、实际值、关键断言和「可信验证通过 / 未通过」状态。

**需要露出的 UI**

- 手册验证命令
- 文件状态徽章
- 编辑器修改与保存
- 终端输出
- Problems 诊断与行号跳转
- 测试结果断言与可信验证状态

**建议标注**

- 不要只看退出码 0
- 只有与手册一致的可信验证命令才会被记录为可信 run



### 5. `report-socratic-review.gif`（3.4，15-20 秒）

**镜头**

1. 进入学习支持的「实验报告」，展示「模板填写 / Markdown 自由编写」下拉切换。
2. 填写一段实验目标或结论，点击「预览」查看最终稿。
3. 可顺带展示一次图片或附件上传插入。
4. 进入苏格拉底复盘，展示「每题一页」的题目、回答区、页码条和「回到当前」。
5. 回答一题后翻页，说明草稿会自动暂存。
6. 切到「学习评价」，点击「生成 / 刷新评价」，展示融合分、过程、收获与反思，以及「未观察到」的细项。
7. 回到报告页点击「提交给老师」，展示二次确认弹窗。

**需要露出的 UI**

- 模板填写 / Markdown 自由编写
- 预览最终稿
- 图片库与附件
- 苏格拉底复盘页码条与回答区
- 学习评价融合分与细项
- 「提交给老师」确认弹窗

**建议标注**

- 正文、附件和复盘记录会一起提交给老师
- 自动评分不会伪造未观察到的证据



### 6. `ai-tutor-evidence.gif`（3.5，10-15 秒）

**镜头**

1. 点击右下角悬浮按钮打开 AI 导师，先展示证据条三列：当前阶段、已有证据、下一步所需。
2. 在代码编辑器里选中一段代码，点击「添加到对话」。
3. 切到测试结果或 Problems，把一条断言或诊断也添加进对话。
4. 展示输入框上方的附件 chips，输入一个符合「判断 + 证据 + 具体问题」的提问并发送。
5. 导师回复后，展示证据条状态变化。
6. 可顺带展示一次「拒答完整实现」的护栏提示。

**需要露出的 UI**

- AI 导师悬浮窗口
- 证据条三列
- 编辑器 / 终端 / Problems / 测试结果的「添加到对话」
- 输入框上方附件 chips
- 导师回复与拒答标记

**建议标注**

- 附件不会自动发送，发送前仍由你决定
- 导师只引导，不替写完整实现



### 7. `teacher-publish-review.gif`（3.6，15-20 秒）

**镜头**

1. 教师登录后从「引导式学习」进入，选择某个 Lab 的「预览、编辑与发布」。
2. 左侧展示手册预览和编辑，右侧展示「教学安排」。
3. 在右侧创建班级或选择一个班级，选择任务类型（补代码、排错等）或「随机分配」。
4. 按全局 / 班级 / 学生范围分发，设置开放或截止时间。
5. 可顺带展示「导出班级名单」。
6. 从顶栏进入「实验验收」，选择一名学生和 Lab。
7. 中栏展示报告正文与复盘记录，右栏展示自动评分、教师最终分、验收建议，最后填写并保存。

**需要露出的 UI**

- 教师端 Lab 列表
- 「预览、编辑与发布」
- 左侧手册编辑
- 右侧教学安排
- 班级、任务类型、分发范围、开放 / 截止时间
- 「批量开放」「管理账号」「管理班级」「查看日程」
- 实验验收队列、报告复盘、自动评分、教师最终分与验收建议

**建议标注**

- 自动评分只提供建议，最终验收由教师完成





## 替换方式

录制完成后，直接把录屏文件覆盖到 `os-lab/handbook/public/gifs/` 下的同名文件即可，不需要修改 `start.md` 的图片路径。当前已有 7 个必选占位文件；如果决定录制可选的 `final-project.gif`，需要先在 `start.md` 中补一个对应图片位置。
