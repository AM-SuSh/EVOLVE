## 统一格式

每个 `labN-answers.md` 固定三节：

1. **完整代码逐行解读** — 帮助对照仓库源码理解实现。
2. **任务二：阅读理解参考答案** — 对应实验文档【任务二】各题。
3. **任务三动手修改的现象参考** — 选做修改的预期现象说明。

## 使用建议

先独立完成实验文档中的【任务二】，再打开对应答案文件核对。不要先翻答案再读题。
