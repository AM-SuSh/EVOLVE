# 文字类习题总览

> 每个 Lab 配套 2-3 道文字类概念理解题，用于巩固对核心知识点的掌握。
> 这些题目**不要求写代码**，而是考察你对概念的理解——做完后再去对应的实验动手，理解会深得多。

## 使用方法

1. 先做完对应 Lab 的实验任务（跑通 + 阅读 + 动手修改）。
2. 再来做这里的文字习题，独立思考写出答案。
3. 最后对照 `labs/answers/labN-answers.md` 里的参考答案（部分习题的答案在各 lab 的"思考题与参考答案"节里）。
