# Lab4 文字习题：进程管理

> 完成 [Lab4 实验](../lab4-process.md) 后做这些题。答案参考 lab4 文档的"六、思考题与参考答案"节和 `labs/answers/lab4-answers.md`。

## 习题 1：fork 为什么"一次调用返回两次"？

fork 是 Unix 最精妙的设计之一。请解释：
- "一次调用返回两次"具体是什么意思？父进程和子进程分别返回什么？
- 内核是怎么实现这种"返回两次"的？（提示：TrapContext 的复制 + 返回值寄存器）
- 如果 fork 只允许返回一次（比如子进程从 main 开头跑），会有什么问题？

## 习题 2：exec 的"换身不换魂"

exec 把当前进程的代码换成另一个程序。请回答：
- "换身不换魂"里的"身"和"魂"分别指什么？哪些变了、哪些没变？
- exec 之后，原程序里 `exec()` 调用之后的代码还会执行吗？为什么？
- 为什么 Unix 把 fork 和 exec 设计成两个独立的系统调用，而不是合成一个"spawn"？

## 习题 3：僵尸进程是什么？为什么要存在？

子进程 exit 后不立刻消失，而是变成 Zombie 状态。请解释：
- 为什么不直接在 exit 时释放资源？
- 僵尸状态保留的是什么信息？给谁用？
- 如果父进程从不调用 wait，会出什么问题？

## 习题 4：wait 的阻塞等待

父进程 wait 时，如果子进程还没退出，父进程怎么办？请回答：
- 父进程为什么不能"原地空转"等子进程退出？
- "阻塞等待"具体是怎么实现的？（提示：loop + 让出 CPU）
- 这种"条件不满足就 sleep、被唤醒再试"的模式，在操作系统里还有什么应用？
