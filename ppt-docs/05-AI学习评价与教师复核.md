# 方向五：AI 学习评价与教师复核（新增部分）

> 初赛基线：无学习评分体系。
> 本次新增：Rubric v3、14 细项、掌握画像、教师复核门控、评分审计与校准。

## 1. Rubric v3

评分结构：

```text
total = 0.45 x process + 0.35 x result + 0.20 x reflection
```

14 个细项：

- process：问题推进、学生判断、证据引用、可证伪假设、可信验证、失败后迭代
- result：Hello、Power、Yield 五轮、全部退出等命名断言
- reflection：独立判断、AI 与验证分工、迁移对照、退出码反例意识

无证据项必须显示“未观察到”，不能凭模型建议补成确定分数。

## 2. 掌握画像

- `GET /mastery` 返回概念掌握状态
- 按概念聚合误区、提示等级、置信度、评价引用
- 评价结果反馈给导师，用于后续个性化追问

## 3. 教师复核门控

强制复核：

| 代号 | 触发 |
| --- | --- |
| H1 | 结果分满分但过程分极低 |
| H2 | Yield 断言存疑 |
| H3 | 反思满分但无 run 证据引用 |
| H4 | 多次护栏触发仍高过程分 |
| H5 | 变体自动分与教师抽检不一致 |
| H6 | 学生申诉 |

建议复核：

- S1：迁移题与本 Lab 证据矛盾
- S2：长时间停滞后突然满分
- S3：同班高度相似报告

## 4. 评分审计

- 教师改分保留原自动分
- 教师修正、理由、证据引用、revision 全部留存
- AI 不拥有最终成绩裁决权
- 评分细项可点击回看 run/trace/报告

## 5. 校准

- 使用 20 条人工标注轨迹离线校准
- 建议就绪阈值从 70 调整为 76
- 假阳性从 3 降为 0
- 准确率从 0.80 提升到 0.95
- 明确标注：构造/标注样本，不是真人试用数据
