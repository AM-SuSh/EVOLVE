## 2. 安全边界

- 默认只监听 `127.0.0.1`
- 远程课堂放在 TLS 反向代理后
- API Key 不写入仓库、前端包、日志或导出
- CORS 来源显式配置
- 学生运行使用服务端可信 recipe、超时、输出上限
- 跨账号 run 访问返回 404
- 游客模式移除

## 3. 备份恢复

- 使用 SQLite backup API 在线创建一致性快照
- 每个备份带 SHA-256、migration、表行数 manifest
- 恢复前校验 manifest 与 SHA-256
- 恢复必须离线、显式确认
- 覆盖前保留旧库 `.pre-restore-*.bak`

## 4. 数据最小化

- 匿名分析默认只输出聚合数据
- 参与者级数据达到最小 cohort 后才输出一次性伪名
- 排除用户名、班级、消息正文、命令、文件路径、原始时间戳
