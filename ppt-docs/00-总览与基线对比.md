# 00. 总览与基线对比

> 本文件保存拆分前总览文档中不属于单一方向的总体内容，避免拆分后信息丢失。

## 1. 一句话总结

初赛交付的是“参考练习全绿 + 自研 Lab1-5 教学内核 + 静态学习手册”；
本次新增的是“Lab6-8 完整内核链路 + 账号制学习工作台 + 教师端 + AI 导师 + AI 学习评价 + 知识库 RAG + Lab Factory + 可信证据链 + 部署运维闭环”。

项目定位也从“一套教学实验环境”扩展为“一套可进课堂的操作系统教学与评价系统”。
