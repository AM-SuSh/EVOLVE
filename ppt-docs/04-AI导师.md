# 方向四：AI 导师（新增部分）

> 初赛基线：只在文档中记录“如何与 AI 协作”，无平台内 AI 导师。
> 本次新增：服务端 AI 导师、七类问题意图、提示等级、答案护栏、证据门控、RAG、评测 Harness。

## 1. 服务端权威控制

核心文件：

- `os-lab/tutor/turn-policy.mjs`：本轮意图识别、问题线程与教学动作规划
- `os-lab/tutor/state-machine.mjs`：旧阶段状态机，用于兼容与遥测
- `os-lab/tutor/evidence-refs.mjs`：run/trace/diag/event 证据引用校验
- `os-lab/tutor/trace-store.mjs`：Trace 存储、哈希校验与分页查询
- `os-lab/handbook/tutor-server.mjs`：导师服务端，负责 Prompt 组装、模型调用与输出校验

核心流程：

```text
学生消息 + Lab + 证据
-> 身份/Lab/证据校验
-> 意图识别与问题线程
-> 答案护栏
-> 可信证据与 RAG 上下文
-> 模型调用
-> 输出校验
-> 返回回复、意图、动作、合法引用
```

## 2. 七类问题意图

| 意图 | 适用问题 |
| --- | --- |
| concept | 概念与机制 |
| code-reading | 源码与调用链 |
| debug | 报错与失败现象 |
| verification | 运行与测试 |
| reflection | 复盘与理解变化 |
| transfer | 对比与迁移 |
| direct-answer | 直接要答案 |

## 3. 提示等级

- L0：观察现象与已有材料
- L1：形成假设
- L2：设计最小验证
- L3：对照路径
- L4：停止泄漏实现

提示等级按 `topicKey` 问题线程累计，换题、换文件、换诊断后归零。

## 4. 答案护栏与证据门控

- 不输出完整文件、完整 patch、可直接提交实现
- 不伪造服务端 run/trace/diag 证据
- 引用只能来自本轮白名单
- 越权引用会丢弃原回复并返回安全追问
- 没有可信 run 时不得声称验证通过

## 5. Prompt 体系

- `tutor/prompts/system.md`：全局导师人设、教学边界与回答风格
- `tutor/prompts/<lab>/context.md`：Lab 专属机制、允许讨论范围与验证标准
- `tutor/prompts/strategies/*.md`：七类问题意图的回答策略
- `tutor/prompts/guardrails.yaml`：完整答案、参考实现与越权请求硬规则
