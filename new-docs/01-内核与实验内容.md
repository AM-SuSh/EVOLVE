# 方向一：内核与实验内容（新增部分）

> 初赛基线：Lab1-5、6 个组件 crate、内嵌只读文件系统
> 本次新增：Lab6-8、os-signal、os-sync、磁盘 FS、信号、线程同步、死锁检测

## 1. 新增 Lab6：磁盘文件系统

新增模块：

- `kernel/src/virtio_block.rs`：VirtIO 块设备
- `kernel/src/fs/disk.rs`：磁盘文件系统
- `kernel/src/fs/embedded.rs`：原 `fs.rs` 迁移后的内嵌只读文件系统
- easy-fs 磁盘镜像与 `fs.img`
- `mmap` / `munmap`、`spawn`、stride 调度、`set_priority` 作为前置能力

新增 syscall：

- `mmap` 222
- `munmap` 215
- `spawn` 400
- `set_priority` 140
- `linkat` 37
- `unlinkat` 35
- `fstat` 80

新增验证：

```text
make test-lab6
```

关键输出：

```text
file_test pass
Test link OK!
mass open/unlink OK!
mmap_test pass
spawn_test pass
stride_test pass
fs_test pass
pipe_test pass
```

## 2. 新增 Lab7：IPC 与信号

新增内容：

- 统一 fd 抽象：Regular、PipeRead、PipeWrite
- `dup` 复制 fd 表项
- 信号 syscall：`kill`、`sigaction`、`sigprocmask`、`sigreturn`
- 新组件 crate：`os-signal`
- 信号默认行为、屏蔽、投递时机
- 管道 fd 在 fork 后引用计数继承

新增验证：

```text
make test-lab7
```

关键输出：

```text
dup_test pass
signal_test pass
signal_mask_test pass
pipe_test pass
```

## 3. 新增 Lab8：线程与同步

新增模块：

- `kernel/src/processor.rs`：进程内多线程
- `kernel/src/sync_syscall.rs`：阻塞式同步原语 syscall
- `kernel/src/deadlock.rs`：死锁检测
- `os-sync`：新组件 crate

新增 syscall：

- 线程：`thread_create` 1000、`gettid` 1001、`waittid` 1002
- mutex：create/lock/unlock 1010-1012
- semaphore：create/up/down 1020-1022
- condvar：create/signal/wait 1030-1032
- 死锁：`enable_deadlock_detect` 469

新增验证：

```text
make test-lab8
```

关键输出：

```text
threads_test pass
threads_arg_test pass
mutex_test pass
condvar_test pass
pipetest passed!
deadlock test mutex 1 OK!
deadlock test semaphore 1 OK!
pipe_test pass
```

## 4. 新增用户态测试程序

Lab6：

- `file_test`：磁盘文件 open/read/close 读写测试
- `link_test`：link 硬链接与 fstat 状态测试
- `mass_unlink_test`：批量 open/unlink 与路径清理测试
- `mmap_test`：mmap/munmap 映射与权限测试
- `spawn_test`：spawn 从 fs.img 加载并运行新程序测试
- `stride_test`：stride 调度与优先级测试
- `lab6_usertest`：Lab6 汇总用户测试入口

Lab7：

- `dup_test`：dup fd 复制与共享测试
- `signal_test`：kill/sigaction 信号投递与处理测试
- `signal_mask_test`：sigprocmask 信号屏蔽测试
- `signal_child`：配合信号测试的子进程
- `lab7_usertest`：Lab7 汇总用户测试入口

Lab8：

- `threads_test`：线程创建、等待与退出码测试
- `threads_arg_test`：线程参数传递测试
- `mutex_test`：阻塞 mutex 临界区计数测试
- `condvar_test`：条件变量 wait/signal 测试
- `pipetest`：fork + 管道通信测试
- `deadlock_mutex_test`：重复加锁触发 `-0xDEAD` 测试
- `deadlock_sem_test`：信号量环路死锁测试
- `lab8_integration_test`：Lab8 全链集成测试，默认 initproc
- `lab8_usertest`：Lab8 汇总用户测试入口
