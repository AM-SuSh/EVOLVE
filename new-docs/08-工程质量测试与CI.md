## 4. 静态质量

- `cargo check --workspace`：全 workspace 编译检查
- `cargo clippy --all -- -D warnings`：静态 lint，开启严格告警检查
- `git diff --check`：检查空白错误与冲突标记
- VitePress build 死链检查：同步内容并验证站点构建与内部链接
