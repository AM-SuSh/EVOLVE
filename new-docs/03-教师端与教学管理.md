# 方向三：教师端与教学管理（新增部分）

> 初赛基线：无教师端。
> 本次新增：教师控制台、开放进度、任务变体、AI 统一配置、班级与报告管理。

## 1. 教师控制台

新增 `/teacher` 教师端：

- 全局、班级、学生三级发布对象
- 作业公告
- 教学进度开放
- 任务分配
- 个别调整
- AI 统一模型配置
- 学生进度列表
- 学生报告在线查看
- 班级名单与导出
- 一键重置学生工作区

## 2. 任务变体

新增 fill/debug 变体：

| Lab | 变体文件 | 变体内容 |
| --- | --- | --- |
| Lab2 | `kernel/src/task.rs` | 协作式调度与任务切换的补全/排错 |
| Lab3 | `kernel/src/mm.rs` | 页表映射与权限管理的补全/排错 |
| Lab4 | `kernel/src/process.rs` | fork/exec/wait 进程语义的补全/排错 |
| Lab5 | `kernel/src/fs/embedded.rs` | fd 表与文件读写的补全/排错 |
| Lab6 | `kernel/src/fs/disk.rs` | 磁盘 FS、link/fstat 的补全/排错 |
| Lab7 | `kernel/src/signal.rs` | 信号注册、投递与屏蔽的补全/排错 |
| Lab8 | `kernel/src/sync_syscall.rs` | 阻塞式同步 syscall 的补全/排错，如 `finish_blocking_syscall`、`sys_mutex_unlock` |

变体统一放在 `os-lab/scaffold/exercises/`，教师可下发 fill、debug 或 random 随机变体。

## 3. AI 统一配置

- 教师填写 OpenAI-compatible 接口地址、模型名、API Key
- 可强制全班统一，或允许学生自配
- 教师端只显示“已设置”，不回填真实 Key
- 支持显式清除统一配置
- 可检测 `/models` 连接状态

## 4. 账号与安全

- 预置管理员 `admin/admin123`，首登必须改密码
- 教学配置保存在 `os-lab/scaffold/teacher.json`
- 学生账号无法访问教师端
- 支持班级管理和班级筛选
