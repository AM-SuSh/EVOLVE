# 方向二：学习平台与学生工作台（新增部分）

> 初赛基线：VitePress 静态学习手册，只有进度勾选、快速开始、验证命令。
> 本次新增：账号制学习平台、代码工作台、可信验证、Trace、实验报告、学习数据持久化。

## 1. 账号与身份

- 注册/登录，注册必填班级
- 学生账号绑定代码工作区、学习事件、报告、AI 会话
- 游客模式移除，站点入口即登录
- 学生代码工作区统一在 `student-labs/<用户名>/`

## 2. 工作台

新增区域：

- 左侧：实验手册
- 右侧上方：Monaco 代码编辑器
- 右侧下方：终端、Problems、测试结果
- 学习支持区：Trace、实验报告、学习评价
- 右下角：AI 导师

新增前端组件：

- `AuthGate`：登录、注册、班级选择与权限门
- `LabWorkspace`：Lab 工作台主布局
- `ManualPane`：左侧实验手册阅读
- `CodePanel`：代码编辑、文件状态与保存
- `TerminalPanel`：终端运行与输出
- `ProblemsPanel`：编译诊断展示与源码跳转
- `TraceViewer`：Trace 查看与回放
- `ReportPanel`：实验报告编辑、附件与提交
- `AssessmentPane`：学习评价细项与证据展示
- `TutorPane`：AI 导师对话入口与面板
- `TeacherNav`：教师端导航
- `TeacherPublishPanel`：教师发布、开放进度与任务分配
- `TeacherReport`：学生报告查看与反馈
- `TeacherReview`：教师复核队列
- `KnowledgeManager`：知识库管理
- `HomeLanding`：首页落地页
- `MaterialsShelf`：学习材料架

## 3. 可信验证

- 服务端可信 recipe
- runId + workspaceVersion
- 命名断言
- 结构化 Trace
- Problems 编译诊断可跳回源码
- 无证据时显示空态，不展示 mock 数据

关键约束：

- 自定义命令退出码 0 不产生 verified=true
- Trace 绑定 runId，跨账号访问返回 404
- 查看 Trace 会记录 `trace_inspected` 学习事件

## 4. 实验报告

- Markdown 编辑与预览
- 模板与自由编辑
- 图片附件上传、引用、自动清理
- 草稿保存、断线重试、本机地址回退
- 正式提交生成 `reports/<labId>/submission.md`
- 报告可插入 run/trace 证据引用

## 5. 学习数据持久化

- SQLite：`learning/os-lab.db` 保存账号、权限、运行状态、断言、评分、报告索引
- 文件系统：`student-data/<userId>/` 保存报告、会话、事件、运行制品
- 服务端保存会话与事件 JSONL
- 解锁规则：可信成功运行 + 带反思报告，再结合教师开放进度

详细文档：

- `os-lab/handbook/guide/start.md`：入门指南，Lab1-8 与 OSTEP 映射、学习方式与最短路径
- `os-lab/handbook/guide/beginner.md`：新手第一次完成 Lab 的完整操作流程
- `os-lab/handbook/README.md`：手册站点结构、内容同步与构建方式
- `os-lab/handbook/docs/workbench-ui.md`：工作台 UI 组件与交互说明
